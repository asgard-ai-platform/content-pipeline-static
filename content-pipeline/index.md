# Content Pipeline — Ad Card Images (jsDelivr CDN)

Public repo, so [jsDelivr's GitHub CDN](https://www.jsdelivr.com/documentation#id-github) can serve these
directly. Pattern: `https://cdn.jsdelivr.net/gh/asgard-ai-platform/content-pipeline-static@main/content-pipeline/<file>`.

Pinned to `@main` — jsDelivr caches by branch for up to 7 days, so a fresh push may take a little while to
show up; append `?v=<anything>` to bust the cache immediately if needed.
